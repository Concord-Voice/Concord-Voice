# Getting started with Concord Voice

Concord Voice provides encrypted voice and messaging.

Self-host distribution is available only through a verified public release. This page does not authorize installation or announce an unreleased version. Self-host releases are published from the Concord-Voice/Self-Hosted repository; consult its [public Releases index](https://github.com/Concord-Voice/Self-Hosted/releases) for published assets and the guide retained with each immutable release tag. If no verified self-host release is listed, an install link is unavailable.
