# Changelog

Each part of Concord Voice now keeps its own changelog and version in its own
repository:

- Desktop app: [Concord-Voice/Desktop](https://github.com/Concord-Voice/Desktop/blob/main/CHANGELOG.md)
- Server and self-host bundle: [Concord-Voice/Self-Hosted](https://github.com/Concord-Voice/Self-Hosted/blob/main/CHANGELOG.md)
- Mobile app: [Concord-Voice/Mobile](https://github.com/Concord-Voice/Mobile/blob/main/CHANGELOG.md)

Until 0.3.0, all parts shared one version and one changelog. Each repository
above keeps that shared history, filtered to its own changes.
