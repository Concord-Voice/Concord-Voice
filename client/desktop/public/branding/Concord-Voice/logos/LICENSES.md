# Logo Licenses — `client/desktop/public/branding/Concord-Voice/logos/`

This directory ships Concord Voice's own brand marks used by the `client/desktop`
Electron client. They are self-hosted (served from the packaged bundle / renderer
`public/`) — never loaded from a CDN, per the no-CDN privacy stance.

## Files shipped

| File                               | Description                        | Owner / License                           |
| ---------------------------------- | ---------------------------------- | ----------------------------------------- |
| `main-logo-transparent-vector.svg` | Full Concord Voice logo (wordmark) | © Concord Voice LLC — all rights reserved |
| `symbol-transparent-vector.svg`    | Concord Voice symbol mark (icon)   | © Concord Voice LLC — all rights reserved |
| `logo-transparent-icon.png`        | Concord Voice icon (raster)        | © Concord Voice LLC — all rights reserved |

## Third-party marks — intentionally NOT shipped

The subscription page's Kickstarter promo card (#1304) links to the Concord Voice
Kickstarter campaign but deliberately does **not** embed the Kickstarter wordmark
or logo — those are Kickstarter, PBC trademarks. The card uses Concord's own
`symbol-transparent-vector.svg` and names the campaign in text instead. If a
Kickstarter-provided badge is ever adopted, add it here with its usage terms and
place the asset in this directory (self-hosted, no CDN).
