# grey on fifteen light schemes. Cosmetic rather than structural, which is why
# css-var-references.test.ts fails the build only on the no-fallback class.
#
# This file is the ratchet for the cosmetic class. The guard asserts the live set
# matches these lines EXACTLY, so:
#   - a NEW undefined-with-fallback reference fails the build
#   - FIXING one also fails the build until its line is deleted here
# The second half is the point. Without it a future no-fallback bug could be
# "fixed" by adding a fallback, and the guard would go green over a live defect.

# belongs here only if it already existed when this file was frozen (PR #3270).

# design decision about the token system, not a rename. That is why they are
# frozen here rather than guessed at.
